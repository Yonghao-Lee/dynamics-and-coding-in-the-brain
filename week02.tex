\section{Where we are}

Week 1 ended with the rate model of a network of $N$ neurons \src{LMLF eq.\ 2.8--2.9}:
\[ \tau\dot r_i = -r_i + g(h_i),\qquad h_i = \sum_{j=1}^N J_{ij}r_j + \hext_i. \]
\begin{itemize}
  \item $r_i$ is the firing rate of neuron $i$; $\tau$ is its time constant ($\sim$10\,ms).
  \item $h_i$ is its total input: what it hears from the other neurons ($J_{ij}r_j$, synapse \emph{from} $j$ \emph{to} $i$) plus external input $\hext_i$.
  \item $g$ is the activation function: it turns input into a rate.
\end{itemize}

\begin{intuition}[The plan for this week]
Before analysing big networks, study the \hl{smallest possible network: one neuron}. If it talks to itself, it already has
\emph{feedback}, and feedback is what makes networks interesting. This week we use it to introduce two tools we will use all course long:
\textbf{fixed points} and their \textbf{stability}.
We do it twice: first with a linear activation function, where everything can be solved exactly, then with a saturating one (\S\ref{sec:nonlin}),
where the same neuron becomes \textbf{bistable} and can store a memory.
\end{intuition}

\section{The autapse}

\begin{defn}[Autapse]
An \term{autapse} is a synapse that a neuron makes \hl{onto itself}: its axon connects back to its own dendrites. A neuron with an autapse is
\emph{the simplest possible network}: one neuron, one connection, of strength $J$ \src{LMLF 2.3.1}.
\end{defn}

\begin{center}
\begin{tikzpicture}[>=Stealth]
  \node[circle,draw=border,line width=1.4pt,fill=surface,minimum size=1.3cm,font=\large] (n) at (0,0) {$r$};
  \draw[->,line width=1.2pt,ink] (-2.6,0) -- (n.west) node[pos=0.35,above,font=\small]{$\hext$};
  \draw[->,line width=1.2pt,pgreen] (n.north east) .. controls (1.6,1.8) and (-1.6,1.8) .. (n.north west)
        node[pos=0.5,above,font=\small]{$J$};
  \draw[->,line width=1.2pt,ink] (n.east) -- (2.4,0) node[right,font=\small]{output rate $r$};
\end{tikzpicture}
\figcap{The autapse (after \src{LMLF Fig.\ 2.6}). The neuron receives an external input $\hext$, and its own output $r$ comes back to it through the synapse of strength $J$.}
\end{center}

With a single neuron, the network equations lose their indices \src{LMLF eq.\ 2.11--2.12}:
\begin{formula}[Autapse dynamics]
\[ \tau\dot r = -r + g(h),\qquad h = Jr + \hext. \]
\end{formula}

\begin{defn}[Excitatory autapse]
We focus on \term{excitatory} autapses, $J>0$: the more the neuron fires, the more input it gives itself. This is \term{positive feedback}.
\end{defn}

\begin{example}[One input value, two sources]
$J=0.5$, $\hext=1$, current rate $r=4$: total input $h = 0.5\cdot4+1 = 3$. Two of the three units of input come from the neuron itself.
\end{example}

\section{The linear autapse}

\begin{defn}[Linear activation function]
The \term{linear} (identity) activation function is $g(h)=h$: the rate equals the input, with no threshold and no saturation \src{LMLF eq.\ 2.4}.
\end{defn}

\begin{pitfall}[Why linear is a simplification]
A real neuron cannot fire at a negative rate, and it cannot fire faster than a few hundred Hz. The linear $g$ ignores both limits. We use it
because the resulting equation is linear, so we can solve it and understand it completely. It is a good approximation when the rate changes only a little.
\end{pitfall}

With $g(h)=h$ the autapse equation becomes
\[ \tau\dot r = -r + Jr + \hext \qquad\Longrightarrow\qquad \boxed{\ \tau\dot r = -(1-J)\,r + \hext\ } \]

\begin{intuition}[Two forces on $r$]
\begin{itemize}
  \item $-r$: the \term{leak}. Left alone, the rate decays back to zero (Week 1).
  \item $+Jr$: the \term{feedback}. The neuron excites itself in proportion to its own rate.
\end{itemize}
The whole story of this week is the \hl{contest between leak and feedback}: who wins depends on whether $J<1$ or $J>1$.
\end{intuition}

This is exactly the equation $\dot n = an + I$ from the Week 1 bonus hour, with $a = -(1-J)/\tau$ and constant input $I=\hext/\tau$. We could solve it right away
(we do so in \S\ref{sec:solution}). But first we introduce an approach that works \emph{even when the equation cannot be solved}: look for the fixed points and ask whether they are stable.

\section{Fixed points}

\begin{defn}[Fixed point]
A \term{fixed point} $r^*$ is a value of $r$ where the dynamics stand still: \hl{$\dot r = 0$}. If the system starts exactly at $r^*$, it stays there forever \src{LMLF 2.3.1}.
\end{defn}

\textbf{Finding it.} Set the right-hand side to zero:
\[ 0 = -(1-J)\,r^* + \hext \qquad\Longrightarrow\qquad \boxed{\ r^* = \frac{\hext}{1-J}\ }\qquad (J\neq1). \]

\begin{example}[Fixed points for $\hext = 1$]
\begin{center}
\renewcommand{\arraystretch}{1.25}
\begin{tabular}{>{\columncolor{border}}c c l}
\thd{$J$} & \cellcolor{border}\thd{$r^*=1/(1-J)$} & \cellcolor{border}\thd{COMMENT}\\
\rowcolor{surface} \cellcolor{border}\color{surface}$0$ & $1$ & no feedback: the rate just copies the input\\
\rowcolor{surface2} \cellcolor{border}\color{surface}$0.5$ & $2$ & feedback doubles the response\\
\rowcolor{surface} \cellcolor{border}\color{surface}$0.9$ & $10$ & strong feedback: ten times the input\\
\rowcolor{surface2} \cellcolor{border}\color{surface}$0.99$ & $100$ & close to $J=1$ the fixed point runs off\\
\rowcolor{surface} \cellcolor{border}\color{surface}$1.5$ & $-2$ & negative! (see below)\\
\end{tabular}
\end{center}
\end{example}

\begin{intuition}[Feedback amplifies]
For $0<J<1$, $r^* = \hext/(1-J) > \hext$: the autapse \hl{amplifies its input by the factor $1/(1-J)$}.
Why: the input raises $r$, which raises the feedback $Jr$, which raises $r$ further, and so on. The extra contributions add up to
$\hext(1+J+J^2+\dots) = \hext/(1-J)$, a geometric series that converges only if $J<1$.
\end{intuition}

\begin{pitfall}[A fixed point is not automatically where the system goes]
For $J=1.5$ the formula gives $r^*=-2$. It is a perfectly valid solution of $\dot r=0$, but (as we will see) the system runs \emph{away} from it.
Also, a negative rate shows that the linear model has left the range where it describes a real neuron. Finding a fixed point is only half the job; the other half is its stability.
\end{pitfall}

\begin{pitfall}[The border case $J=1$]
For $J=1$ the leak and the feedback cancel exactly: $\tau\dot r = \hext$. If $\hext\neq0$ there is \emph{no} fixed point ($r$ grows or shrinks steadily).
If $\hext=0$ then $\dot r=0$ everywhere: \emph{every} value of $r$ is a fixed point. The book returns to this special case later (\S4.2); this week we assume $J\neq1$.
\end{pitfall}

\section{Stability}

\subsection{The idea}

\begin{defn}[Stable and unstable fixed points]
Start the system \emph{near} $r^*$ instead of exactly on it.
\begin{itemize}
  \item If the dynamics bring $r$ \hl{ever closer} to $r^*$, the fixed point is \term{stable}.
  \item If the dynamics \hl{push $r$ away} from $r^*$, the fixed point is \term{unstable}.
\end{itemize}
\end{defn}

\begin{intuition}[Why stability matters]
In the real brain the rate is never exactly at $r^*$: there is always noise. An unstable fixed point is never seen in practice, because the
tiniest disturbance grows. Only \hl{stable fixed points describe states the network actually sits in}.
\end{intuition}

\subsection{Perturbation analysis, step by step}

To decide stability, follow a small deviation from the fixed point \src{LMLF eq.\ 2.14--2.15}.

\begin{defn}[Perturbation]
The \term{perturbation} is the distance from the fixed point: $\dr(t) = r(t)-r^*$. Equivalently $r = r^*+\dr$.
\end{defn}

\begin{enumerate}
  \item \textbf{Substitute} $r = r^*+\dr$ into $\tau\dot r = -r+Jr+\hext$:
        \[ \tau\frac{d}{dt}(r^*+\dr) = -(r^*+\dr) + J(r^*+\dr) + \hext. \]
  \item \textbf{$r^*$ is a number, not a function of time}, so $\frac{d}{dt}r^* = 0$ and the left side is $\tau\,\dot{\dr}$.
  \item \textbf{Regroup the right side} into the part with $r^*$ and the part with $\dr$:
        \[ \tau\,\dot{\dr} = \underbrace{\big(-r^*+Jr^*+\hext\big)}_{=\,0\ \text{(definition of } r^*)} + \big(-\dr + J\dr\big). \]
  \item \textbf{The first bracket vanishes} because $r^*$ is a fixed point. What remains is
        \[ \boxed{\ \tau\,\dot{\dr} = -(1-J)\,\dr\ } \]
\end{enumerate}

\begin{intuition}[What happened]
The external input $\hext$ has disappeared. It only decides \emph{where} the fixed point is; whether the fixed point is stable depends only on $J$.
\end{intuition}

\subsection{Reading off stability from the sign}

\textbf{Case $J<1$}, so $1-J>0$:
\begin{itemize}
  \item if $\dr>0$ (rate above the fixed point) then $\dot{\dr}<0$: it comes down;
  \item if $\dr<0$ (rate below) then $\dot{\dr}>0$: it goes up.
\end{itemize}
Either way the perturbation shrinks. \hl{The fixed point is stable.}

\textbf{Case $J>1$}, so $1-J<0$: now $\dot{\dr}$ has the \emph{same} sign as $\dr$. Above the fixed point the rate rises further; below it, it falls further.
\hl{The fixed point is unstable.}

\begin{formula}[Stability of the linear autapse]
\[ J<1\ \Rightarrow\ \text{stable}\qquad\qquad J>1\ \Rightarrow\ \text{unstable} \]
$J=1$ is the border between two qualitatively different behaviours.
\end{formula}

\begin{intuition}[Leak vs.\ feedback again]
$J<1$: when the rate goes up by $\dr$, the leak pulls it down by $\dr$ but the feedback pushes it up only by $J\dr<\dr$. Leak wins, the deviation dies.
$J>1$: the feedback push $J\dr$ beats the leak, the deviation feeds itself.
\end{intuition}

\subsection{How fast? Solving for $\dr(t)$}

$\tau\dot{\dr} = -(1-J)\dr$ is the Week 1 equation $\dot n = an$ with $a = -(1-J)/\tau$, so \src{LMLF eq.\ 2.16}
\begin{formula}[Perturbation over time]
\[ \dr(t) = \dr(0)\,e^{-(1-J)t/\tau}. \]
\end{formula}
\begin{itemize}
  \item $J<1$: exponential \textbf{decay} to $0$, i.e.\ $r(t)\to r^*$.
  \item $J>1$: exponential \textbf{growth}; $r$ diverges to $+\infty$ or $-\infty$, depending on the sign of $\dr(0)$.
\end{itemize}

\begin{example}[How long a perturbation lasts, $\tau = 10$\,ms]
The perturbation shrinks (or grows) by a factor $e$ every $\tau/|1-J|$:
\begin{center}
\renewcommand{\arraystretch}{1.25}
\begin{tabular}{>{\columncolor{border}}c c c}
\thd{$J$} & \cellcolor{border}\thd{$\tau/|1-J|$} & \cellcolor{border}\thd{BEHAVIOUR}\\
\rowcolor{surface} \cellcolor{border}\color{surface}$0$ & 10\,ms & decays (just the leak)\\
\rowcolor{surface2} \cellcolor{border}\color{surface}$0.5$ & 20\,ms & decays, twice as slowly\\
\rowcolor{surface} \cellcolor{border}\color{surface}$0.9$ & 100\,ms & decays, ten times as slowly\\
\rowcolor{surface2} \cellcolor{border}\color{surface}$1.5$ & 20\,ms & grows by $e$ every 20\,ms\\
\end{tabular}
\end{center}
The closer $J$ is to $1$, the \hl{slower} everything happens: stronger feedback lets the neuron hold on to a deviation for much longer than its own $\tau$.
\end{example}

\section{The full solution}\label{sec:solution}

Using the Week 1 result for $\dot n = an + I$ with constant input (or simply $r = r^*+\dr$ with $\dr(t)$ from above):
\begin{formula}[Linear autapse, solved]
\[ r(t) = r^* + \big(r(0)-r^*\big)\,e^{-(1-J)t/\tau},\qquad r^*=\frac{\hext}{1-J}. \]
\end{formula}

\textbf{Check.} At $t=0$: $r(0) = r^* + r(0) - r^* = r(0)$ \checkmark. Differentiate:
$\tau\dot r = -(1-J)(r(0)-r^*)e^{-(1-J)t/\tau} = -(1-J)(r-r^*) = -(1-J)r + (1-J)r^* = -(1-J)r + \hext$. \checkmark

\begin{example}[Starting from silence, $r(0)=0$, $\hext=1$, $\tau=10$\,ms]
\begin{center}
\renewcommand{\arraystretch}{1.2}
\begin{tabular}{c|cccccc}
$t$ (ms) & 0 & 10 & 20 & 40 & 60 & 100\\\hline
$J=0.5$: \ $2(1-e^{-t/20})$ & 0 & 0.79 & 1.26 & 1.73 & 1.90 & 1.99\\
$J=0.9$: \ $10(1-e^{-t/100})$ & 0 & 0.95 & 1.81 & 3.30 & 4.51 & 6.32\\
$J=1.5$: \ $-2+2e^{t/20}$ & 0 & 1.30 & 3.44 & 12.8 & 38.2 & 295\\
\end{tabular}
\end{center}
$J=0.5$ settles at $2$ within $\sim$60\,ms. $J=0.9$ heads for $10$ but needs hundreds of ms. $J=1.5$ starts \emph{above} its fixed point $-2$, so it is pushed further and further up, without limit.
\end{example}

\section{The geometric view: the vector field}

We can see stability \emph{without solving anything}, by plotting $\dot r$ as a function of $r$ (the idea from the Week 1 bonus hour).

\begin{defn}[Vector field on a line]
The equation $\tau\dot r = F(r)$ assigns a velocity $\dot r$ to every value of $r$: a \term{vector field} on the line \src{LMLF 2.3.1}.
Draw $\dot r$ against $r$ and put arrows on the $r$-axis: \hl{right where $\dot r>0$, left where $\dot r<0$}. The fixed points are where the graph crosses zero.
\end{defn}

\begin{formula}[Stability from the slope]
A fixed point is stable if the graph of $\dot r$ against $r$ crosses zero going \textbf{down} (negative slope),
and unstable if it crosses going \textbf{up} (positive slope). For the linear autapse the slope is $-(1-J)/\tau$: negative exactly when $J<1$.
\end{formula}

\begin{intuition}[Why this is powerful]
This picture needs only the \emph{sign} of $\dot r$ around $r^*$. It works for equations we cannot solve, which will be the usual case once $g$ is not linear.
\end{intuition}

\section{Connection to Week 1: it is the eigenvalue}

In the TA session of Week 1 we saw that $\dot{\vec x} = M\vec x$ converges iff all eigenvalues of $M$ are negative. The perturbation equation
\[ \dot{\dr} = \underbrace{-\frac{1-J}{\tau}}_{\text{a }1\times1\text{ ``matrix''}}\,\dr \]
is the one-dimensional case: its only eigenvalue is $-(1-J)/\tau$, negative exactly when $J<1$. \hl{Stability of a fixed point = the sign of the eigenvalue of the perturbation dynamics.}
For networks of many neurons the same recipe gives a matrix, and Week 1's eigenvalue tools take over.

\section{A limitation of the linear model}

\begin{pitfall}[Divergence is not biology]
For $J>1$ the linear autapse fires at a rate that grows without bound (or goes to $-\infty$). Real neurons \emph{saturate}: their rate cannot exceed a few hundred Hz,
and it cannot go below zero. This is a limitation of the linear $g$, not of the autapse itself. It is the reason the book next replaces $g(h)=h$
by a saturating activation function \src{LMLF 2.3.1}.
\end{pitfall}

\section{The non-linear autapse: a saturating activation function}\label{sec:nonlin}

The rest of this week keeps the \emph{same} autapse, $\tau\dot r = -r + g(Jr+\hext)$, and changes only $g$. The result is
surprising: a single neuron with strong feedback no longer explodes. Instead it gets \hl{two} stable states, and it can use them to \hl{remember} a bit of information.

Two misreadings to clear up first:
\begin{itemize}
  \item \textbf{The non-linearity does not make the analysis hopeless.} We can no longer write down $r(t)$, but fixed points and their stability can still be found, with a picture.
  \item \textbf{Stability is no longer a property of the whole system.} For the linear autapse, $J$ alone decided stability. Now each fixed point has \emph{its own} stability, and one neuron can have a stable and an unstable fixed point side by side.
\end{itemize}

\subsection{The logistic function}

\begin{defn}[Logistic activation function]
The \term{logistic function} \src{LMLF eq.\ 2.2} is
\[ g(x) = \frac{1}{1+e^{-\beta(x-\theta)}}. \]
It is \term{sigmoidal} (S-shaped): it increases monotonically, it is bounded below by $0$ (no negative rates) and above by $1$ (saturation).
The rate $r$ is therefore \emph{normalised}: $r=1$ means ``firing at the neuron's maximal rate'', not 1\,Hz \src{LMLF 2.2}.
\end{defn}

It has two parameters:
\begin{defn}[Threshold $\theta$ and gain $\beta$]
\begin{itemize}
  \item The \term{threshold} $\theta$ is the input at which the rate is exactly half its maximum: $g(\theta) = 1/(1+e^0) = 0.5$. Changing $\theta$ slides the curve left or right.
  \item The \term{gain} $\beta$ sets how steep the curve is. Its maximal slope, reached at $x=\theta$, is $\beta/4$ (derived below).
\end{itemize}
\end{defn}

\begin{example}[The logistic function with $\theta=0$, $\beta=20$ (the book's values)]
\begin{center}
\renewcommand{\arraystretch}{1.2}
\begin{tabular}{c|ccccccccc}
$x$ & $-0.3$ & $-0.2$ & $-0.1$ & $-0.05$ & $0$ & $0.05$ & $0.1$ & $0.2$ & $0.3$\\\hline
$g(x)$ & 0.002 & 0.018 & 0.119 & 0.269 & 0.5 & 0.731 & 0.881 & 0.982 & 0.998\\
$g'(x)$ & 0.05 & 0.35 & 2.1 & 3.9 & 5 & 3.9 & 2.1 & 0.35 & 0.05\\
\end{tabular}
\end{center}
Almost all of the change happens for $x$ between $-0.2$ and $0.2$. Outside that window the neuron is either nearly silent or nearly saturated, and the slope is close to $0$.
\end{example}

\textbf{The slope of the logistic function}, step by step (we need it for stability). Write $u = e^{-\beta(x-\theta)}$, so $g = 1/(1+u)$ and $du/dx = -\beta u$:
\[ g'(x) = -\frac{1}{(1+u)^2}\cdot(-\beta u) = \beta\,\frac{1}{1+u}\cdot\frac{u}{1+u} = \beta\,g(x)\big(1-g(x)\big). \]
The product $g(1-g)$ is largest when $g=\tfrac12$, i.e.\ at $x=\theta$, where it equals $\tfrac14$. So
\begin{formula}[Slope of the logistic]
\[ g'(x) = \beta\,g(x)\,\big(1-g(x)\big),\qquad \max_x g'(x) = g'(\theta) = \frac{\beta}{4}. \]
\end{formula}

\subsection{The fixed-point equation}

Setting $\dot r = 0$ in $\tau\dot r = -r + g(Jr+\hext)$ gives \src{LMLF eq.\ 2.17}
\begin{formula}[Fixed points of the non-linear autapse]
\[ r^* = g\big(Jr^* + \hext\big). \]
\end{formula}

\begin{pitfall}[You cannot solve this for $r^*$ with algebra]
$r^*$ appears on both sides, once inside an exponential. There is no formula like $r^* = \hext/(1-J)$ any more. Do not try to isolate $r^*$.
Instead, read the equation as a question about two curves.
\end{pitfall}

\textbf{The geometric method}, step by step:
\begin{enumerate}
  \item \textbf{Left side}: plot $y = r$ against $r$. This is the identity line (slope $1$).
  \item \textbf{Right side}: plot $y = g(Jr+\hext)$ against $r$. As a function of $r$ this is \emph{again a logistic function}, with new parameters. Substitute $x = Jr+\hext$:
        \[ \beta\big(Jr+\hext-\theta\big) = (\beta J)\Big(r - \frac{\theta-\hext}{J}\Big), \]
        so it has \term{effective gain} $\beta J$ and \term{effective threshold} $(\theta-\hext)/J$ \src{LMLF 2.3.1}.
  \item \textbf{Every intersection} of the two curves satisfies $r = g(Jr+\hext)$, so it is a fixed point. Counting intersections counts fixed points.
\end{enumerate}

\begin{intuition}[What $\hext$ does in the picture]
$\hext$ appears only in the effective threshold $(\theta-\hext)/J$. Raising $\hext$ \hl{lowers the threshold, so it slides the S-curve to the left}, along the $r$ axis.
The neuron then reaches half its maximal rate already at a smaller $r$, because the external input supplies part of the drive.
\end{intuition}

\begin{pitfall}[Left, not right]
The book writes that increasing $\hext$ ``results in a shift of the logistic function to the right''. As a function of $r$, the curve moves to the \emph{left}: its midpoint
$(\theta-\hext)/J$ decreases when $\hext$ grows. Check with the book's own numbers ($\theta=0$, $J=1$): the midpoint is at $r=1$ for $\hext=-1$, at $r=0.5$ for $\hext=-0.5$ and at $r=0$ for $\hext=0$.
The figure below (and \src{LMLF Fig.\ 2.7}) shows exactly this leftward slide.
\end{pitfall}

\end{itemize}

\subsection{Stability from the vector field}

We read stability off the bottom row, exactly as in the linear case: arrows pointing \emph{in} mean stable, arrows pointing \emph{out} mean unstable.

\begin{example}[The sign of $\tau\dot r$ for $\hext = -0.5$]
\begin{center}
\renewcommand{\arraystretch}{1.2}
\begin{tabular}{c|ccccccccc}
$r$ & 0 & 0.1 & 0.25 & 0.4 & \textbf{0.5} & 0.6 & 0.75 & 0.9 & 1\\\hline
$g(r-0.5)$ & 0.000 & 0.000 & 0.007 & 0.119 & 0.5 & 0.881 & 0.993 & 1.000 & 1.000\\
$\tau\dot r$ & $\approx0$ & $-0.10$ & $-0.24$ & $-0.28$ & \textbf{0} & $+0.28$ & $+0.24$ & $+0.10$ & $\approx0$\\

\end{tabular}
\end{center}
Between $0$ and $0.5$ the rate falls, towards $0$. Between $0.5$ and $1$ it rises, towards $1$. So $0$ and $1$ attract, and $0.5$ repels:
it is the \hl{watershed} that decides which way the neuron goes.
\end{example}

For a single fixed point (left and right panels) the arrows point towards $r^*$ from \emph{every} starting value. For three fixed points, the outer ones attract only the
starting values on their own side of $0.5$. The book separates these two situations \src{LMLF 2.3.1}:

\begin{defn}[Global and local stability]
\begin{itemize}
  \item A fixed point is \term{globally stable} if the dynamics reach it from \hl{every} starting value $r\neq r^*$. Example: the only fixed point for $\hext=-1$.
  \item It is \term{locally stable} if the dynamics reach it from every starting value \hl{close enough} to it, but not necessarily from far away.
        Example: $r^*\approx0$ for $\hext=-0.5$. Starting at $r=0.3$ leads there, starting at $r=0.7$ does not.
\end{itemize}
Every globally stable fixed point is locally stable; the converse is false.
\end{defn}

\subsection{Stability by linearisation}

The picture is convincing, but we also want a number, as in the linear case. The trick is to make the equation linear near the fixed point.

\begin{defn}[First-order Taylor expansion]
Near a point $a$, a smooth function is approximately a straight line: $\;f(a+\varepsilon) \approx f(a) + f'(a)\,\varepsilon\;$ for small $\varepsilon$.
\textbf{Example}: $g(x)=1/(1+e^{-20x})$ at $a=0.1$, with $\varepsilon=0.01$. Exact: $g(0.11) = 0.9002$. Approximation: $g(0.1)+g'(0.1)\cdot0.01 = 0.8808+2.1\cdot0.01 = 0.9018$. Close, because $\varepsilon$ is small.
\end{defn}

Follow the same recipe as for the linear autapse \src{LMLF eq.\ 2.18--2.22}:
\begin{enumerate}
  \item \textbf{Substitute} $r = r^*+\dr$:
        \[ \tau\frac{d}{dt}(r^*+\dr) = -(r^*+\dr) + g\big(J(r^*+\dr)+\hext\big). \]
  \item \textbf{Name the input at the fixed point} $h^* = Jr^*+\hext$. The argument of $g$ is then $h^* + J\dr$.
  \item \textbf{Taylor-expand} $g$ around $h^*$ with the small step $\varepsilon = J\dr$:
        \[ g(h^*+J\dr) \approx g(h^*) + g'(h^*)\,J\dr. \]
  \item \textbf{Regroup} (and use $\frac{d}{dt}r^*=0$):
        \[ \tau\,\dot{\dr} = \underbrace{\big(-r^*+g(h^*)\big)}_{=\,0\ \text{(fixed point)}} - \dr + Jg'(h^*)\,\dr. \]
  \item \textbf{Result}, with the number $\lambda = Jg'(h^*) = Jg'(Jr^*+\hext)$:
        \[ \boxed{\ \tau\,\dot{\dr} = -(1-\lambda)\,\dr\ }\qquad\Longrightarrow\qquad \dr(t) = \dr(0)\,e^{-(1-\lambda)t/\tau}. \]
\end{enumerate}

\begin{formula}[Local stability of a fixed point of the autapse]
\[ \lambda = J\,g'\big(Jr^*+\hext\big):\qquad \lambda<1\ \Rightarrow\ \text{stable},\qquad \lambda>1\ \Rightarrow\ \text{unstable}. \]
\end{formula}

\begin{intuition}[The same equation as before, with $J$ replaced by $\lambda$]
Compare with $\tau\dot{\dr} = -(1-J)\dr$ for the linear autapse. Near a fixed point, the non-linear neuron behaves like a \emph{linear} autapse whose feedback strength is the
\hl{effective feedback} $\lambda = Jg'(h^*)$: the synaptic weight times how sensitive the neuron is at its current operating point. For $g(h)=h$, $g'=1$ and $\lambda=J$: we recover the old result.
\end{intuition}

\begin{example}[$\lambda$ at the three fixed points for $\hext=-0.5$ ($J=1$, $\beta=20$, $\tau=10$\,ms)]
Use $g' = \beta g(1-g)$ and $g(h^*) = r^*$ at a fixed point, so $\lambda = J\beta\,r^*(1-r^*)$:
\begin{center}
\renewcommand{\arraystretch}{1.25}
\begin{tabular}{>{\columncolor{border}}c c c l}
\thd{$r^*$} & \cellcolor{border}\thd{$\lambda = 20\,r^*(1-r^*)$} & \cellcolor{border}\thd{VERDICT} & \cellcolor{border}\thd{TIME SCALE $\tau/|1-\lambda|$}\\
\rowcolor{surface} \cellcolor{border}\color{surface}$0.000045$ & $0.0009$ & stable & $\approx10$\,ms decay\\
\rowcolor{surface2} \cellcolor{border}\color{surface}$0.5$ & $5$ & unstable & $2.5$\,ms growth\\
\rowcolor{surface} \cellcolor{border}\color{surface}$0.99995$ & $0.0009$ & stable & $\approx10$\,ms decay\\
\end{tabular}
\end{center}
At the outer fixed points the neuron is silent or saturated, so the curve is flat ($g'\approx0$): feedback does nothing and only the leak acts. At $0.5$ the curve is steepest:
a deviation of $0.01$ grows by a factor $e$ every $2.5$\,ms.
\end{example}

\textbf{The geometric version.} $\lambda = Jg'(Jr^*+\hext) = \frac{d}{dr}\,g(Jr+\hext)\big|_{r^*}$ is the \hl{slope of the S-curve at the intersection}. The identity line has slope $1$. So:
\begin{formula}[Stability at a glance]
In the top-row picture, a fixed point is \textbf{stable} if the S-curve crosses the identity line \textbf{less steeply} than it (slope $<1$), and \textbf{unstable} if it crosses \textbf{more steeply} (slope $>1$).
\end{formula}
Look again at the figure: the single crossings (left, right) and the two outer crossings (middle) are flat; the middle crossing is steep.

\subsection{Bifurcations}

As $\hext$ increases smoothly from $-1$ to $0$, the number of fixed points jumps: $1\to3\to1$. This kind of event has a name \src{LMLF 2.3.1}.

\begin{defn}[Bifurcation]
A \term{bifurcation} is a \emph{qualitative} change in the dynamics (fixed points appear or disappear, or a fixed point changes its stability) caused by a \emph{smooth} change of a parameter.
The parameter values where it happens are the \term{bifurcation points}.
\end{defn}

\begin{defn}[Saddle-node bifurcation]
In a \term{saddle-node bifurcation} a stable and an unstable fixed point move towards each other, merge into one, and disappear (or, run backwards, are born together out of nothing).
Both transitions of the autapse are of this type. At the moment of merging, the S-curve just \hl{touches} the identity line: the two curves are tangent.
\end{defn}

\begin{example}[Computing the two bifurcation points ($\theta=0$, $\beta=20$, $J=1$)]
At a bifurcation point the S-curve is tangent to the identity line, so two conditions hold at once:
\begin{enumerate}
  \item it is a fixed point: $r^* = g(h^*)$, with $h^* = r^*+\hext$;
  \item the slopes are equal: $\lambda = J\beta\,g(1-g) = 1$, i.e.\ $20\,r^*(1-r^*) = 1$.
\end{enumerate}
\textbf{Step 1.} Condition 2 is a quadratic: $r^{*2} - r^* + 0.05 = 0$, so $r^* = \tfrac12\big(1\pm\sqrt{0.8}\big)$, i.e.\ $r^* = 0.947$ or $r^* = 0.053$.\\
\textbf{Step 2.} Invert the logistic to find the input: $g(h^*)=r^*$ gives $h^* = \frac{1}{\beta}\ln\frac{r^*}{1-r^*}$. For $r^*=0.947$: $h^* = \frac{1}{20}\ln 17.9 = 0.144$. For $r^*=0.053$: $h^*=-0.144$.\\
\textbf{Step 3.} $\hext = h^* - Jr^*$: \;$0.144-0.947 = \mathbf{-0.803}$ \;and\; $-0.144-0.053 = \mathbf{-0.197}$.\\[2pt]
So the autapse has three fixed points exactly for $-0.803 < \hext < -0.197$. The book's examples $\hext=-1$ (below), $-0.5$ (inside), $0$ (above) fall where they should.
\end{example}

The whole story fits in one picture: plot every fixed point against $\hext$.
\begin{defn}[Bifurcation diagram]
A \term{bifurcation diagram} plots the fixed points (vertical axis) against a parameter (horizontal axis). Stable fixed points are drawn solid, unstable ones dashed.
\end{defn}

\subsection{Attractors and bistability}

\begin{defn}[State space and attractor]
The \term{state space} is the set of all possible states of the system; for the autapse it is just the $r$ axis.
An \term{attractor} is a region of state space to which all nearby trajectories converge \src{LMLF 2.3.1}. A stable fixed point is the simplest attractor; others appear later in the course.
\end{defn}

\begin{defn}[Bistability]
A system is \term{bistable} if it has \hl{two stable fixed points} (two attractors). Between them there is always an unstable fixed point, which separates the starting values that go to one from those that go to the other.
The autapse is bistable for $-0.803<\hext<-0.197$ (with $\theta=0$, $\beta=20$, $J=1$).
\end{defn}

\subsection{Memory: switching with a brief input}

Why care about two stable states? Because a bistable neuron can \hl{store one bit} \src{LMLF 2.3.1}. Left alone in the bistable range, it stays forever in whichever state it is in.
To write a bit, change $\hext$ \emph{briefly}:

\begin{enumerate}
  \item The neuron rests in the low state, $\hext=-0.5$.
  \item A brief pulse raises $\hext$ to $0$, \emph{above} the bifurcation point $-0.197$. Now the low fixed point no longer exists; the only attractor is the high one, and $r$ starts climbing.
  \item The pulse ends: $\hext$ returns to $-0.5$. The low state exists again, but if $r$ has already passed the watershed $0.5$, it keeps going to the high state.
  \item The neuron stays high indefinitely, although the input that put it there is long gone. That is memory.
  \item To erase, pulse $\hext$ \emph{below} $-0.803$ (here to $-1$): the high state disappears and the neuron falls back to the low one, where it stays.
\end{enumerate}

\begin{intuition}[The state depends on history]
At $t=10$\,ms and at $t=60$\,ms the input is the same, $\hext=-0.5$, but the rate is $0$ in one case and $0.98$ in the other. The difference is \hl{what happened before}.
This dependence on past input (often called \term{hysteresis}) is what lets a single neuron with feedback hold information; the book develops it into a model of long-term memory in Ch.\ 5.
\end{intuition}

\begin{pitfall}[The pulse must be long enough]
Raising $\hext$ is not enough by itself; the rate must cross the watershed $0.5$ \emph{before} the pulse ends. With the same parameters, a 5\,ms pulse to $\hext=0$ brings $r$ only to $0.36$.
When $\hext$ returns to $-0.5$, the rate is on the low side of $0.5$ and decays back to $0$: nothing is stored.
\end{pitfall}

\subsection{The two ingredients: positive feedback and saturation}

What makes bistability possible? We need an S-curve that can cross the identity line three times. Two things are required \src{LMLF 2.3.1}:
\begin{itemize}
  \item \textbf{Positive feedback} that is strong enough: in the middle crossing the S-curve must be steeper than $1$. Its maximal slope is $(\beta J)/4$ (the effective gain over $4$), so we need
        \[ \boxed{\ \frac{\beta J}{4} > 1\ }. \]
        If this fails, the S-curve is flatter than the identity line everywhere and crosses it only once, whatever $\hext$ is. If it holds, a suitable $\hext$ produces three crossings.
  \item \textbf{Saturation}: the curve must bend back below the identity line at high $r$ (and stay above it at low $r$). That is what the bounded logistic function provides,
        and what the linear $g$ lacked: there, $J>1$ meant an unstable fixed point and divergence, with no second stable state to land in.
\end{itemize}

\begin{example}[How much feedback is enough? ($\beta=20$)]
$\beta J/4 > 1 \iff J > 4/\beta = 0.2$. With the book's $J=1$: $\beta J/4 = 5$, comfortably bistable for some range of $\hext$. With $J=0.1$: $\beta J/4 = 0.5$, one fixed point for every $\hext$, no memory.
\end{example}

\begin{pitfall}[Three intersections, not two]
The book says that the bistable regime has ``two intersection points''. It has \emph{three} intersections (fixed points), of which \emph{two} are stable. The unstable middle one is always there, between the two attractors.
\end{pitfall}

\subsection{A technical aside: the case $\lambda = 1$}

The linearisation decides stability whenever $\lambda\neq1$. When $\lambda=1$ exactly, it gives $\tau\dot{\dr}=0$, which says nothing. This happens precisely at the bifurcation points, where the S-curve is tangent to the identity line.

\textbf{Step 1: expand one order further} \src{LMLF eq.\ 2.23--2.25}. A second-order Taylor expansion adds the curvature term:
\[ g(h^*+J\dr) \approx g(h^*) + g'(h^*)J\dr + \tfrac12 g''(h^*)J^2\dr^2. \]
\textbf{Step 2: substitute}. The constant term vanishes (fixed point) and the linear term vanishes ($\lambda=1$), leaving
\[ \tau\,\dot{\dr} = \tfrac12 J^2 g''(h^*)\,\dr^2. \]
\textbf{Step 3: read the sign.} $\dr^2>0$ on \emph{both} sides of $r^*$, so $\dot{\dr}$ has the same sign (that of $g''$) on both sides. The flow goes towards $r^*$ on one side and away on the other.

\begin{defn}[Half-stable fixed point]
A fixed point is \term{half-stable} if the dynamics approach it from one side and leave it on the other.
\end{defn}

\textbf{Step 4: solve} (the equation is separable): $\displaystyle\frac{d\dr}{\dr^2} = c\,dt$ with $c = \frac{J^2g''(h^*)}{2\tau}$, so $-\frac{1}{\dr} = ct + \text{const}$ and
\[ \dr(t) = \frac{1}{1/\dr(0) - c\,t}. \]
This is \term{hyperbolic}, not exponential: much slower near the fixed point.

\begin{example}[At the bifurcation point $\hext=-0.803$ ($\beta=20$, $J=1$, $\tau=10$\,ms)]
Here $r^*=0.947$, and $g'' = \beta^2 g(1-g)(1-2g) = 400\cdot0.947\cdot0.053\cdot(-0.894) = -17.9$, so $c = -17.9/20 = -0.89$ per ms.
\begin{itemize}
  \item From above, $\dr(0)=+0.01$: $\dr(t) = 1/(100+0.89t)$. After $100$\,ms it is $0.0053$: only halved. (An exponential decay with $\tau=10$\,ms would have shrunk it $e^{10}\approx 22\,000$-fold.)
  \item From below, $\dr(0)=-0.01$: $\dr(t) = 1/(-100+0.89t)$ grows in size and the approximation breaks down after about $100$\,ms; the neuron leaves towards the low state.
\end{itemize}
\end{example}

\begin{pitfall}[Linearisation tells you only about the neighbourhood]
Both the first- and second-order expansions are valid only while $\dr$ is small. They decide \emph{local} stability. Whether a fixed point is reached from far away (global stability) needs the full picture, such as the vector field \src{LMLF 2.3.1}.
And $\lambda=1$ exactly is a knife-edge: the slightest change of $\hext$ makes $\lambda\neq1$, and the exponential behaviour takes over again.
\end{pitfall}

\section{Practice problems with full solutions}

\begin{example}[P1: Fixed point and stability]
$\tau\dot r = -r + 0.8r + 3$. Find $r^*$, decide stability, and give $r(t)$ for $r(0)=0$, $\tau=10$\,ms.

\textbf{Solution.} $J=0.8$, $\hext=3$: $r^* = 3/0.2 = 15$. $J<1$, so stable. $r(t) = 15(1-e^{-0.2t/10}) = 15(1-e^{-t/50})$: the time scale is $50$\,ms, five times $\tau$.
\end{example}

\begin{example}[P2: Which $J$ gives a target rate?]
With $\hext=2$, what $J$ makes the stable fixed point $r^*=8$?

\textbf{Solution.} $8 = 2/(1-J)\Rightarrow 1-J = 0.25\Rightarrow J=0.75$. Since $0.75<1$ it is stable. \checkmark
\end{example}

\begin{example}[P3: Perturbation by hand]
$J=1.2$, $\hext=-0.4$, $\tau=10$\,ms. Find $r^*$. The rate starts at $r(0)=2.1$; what is it after $50$\,ms?

\textbf{Solution.} $r^* = -0.4/(1-1.2) = -0.4/(-0.2) = 2$. $J>1$: unstable. $\dr(0)=0.1$, and $\dr(t) = 0.1\,e^{0.2t/10} = 0.1\,e^{t/50}$.
At $t=50$: $\dr = 0.1e\approx0.27$, so $r\approx2.27$. The rate drifts away from $2$, slowly at first and then faster and faster.
\end{example}

\begin{example}[P4: Vector field]
Sketch $\tau\dot r$ against $r$ for $\tau\dot r = -0.5r + 1$ and use it to say what happens from $r(0)=5$.

\textbf{Solution.} A line with slope $-0.5$ crossing zero at $r^*=2$. At $r=5$: $\tau\dot r = -1.5<0$, so $r$ decreases, and it keeps decreasing until it reaches $2$.
The arrows point towards $2$ from both sides: stable.
\end{example}

\begin{example}[P5: The border]
What happens for $J=1$, $\hext=0.5$, $\tau=10$\,ms, $r(0)=0$?

\textbf{Solution.} $\tau\dot r = 0.5$, so $\dot r = 0.05$ per ms: $r(t)=0.05t$, a straight line. There is no fixed point; the rate grows steadily, not exponentially.
\end{example}

\subsection*{The non-linear autapse}

\begin{example}[P6: Reading a logistic function]
$g(x) = 1/(1+e^{-10(x-0.2)})$. Find $g(0.2)$, $g(0.4)$, $g(0)$ and the maximal slope.

\textbf{Solution.} $\theta=0.2$, $\beta=10$. $g(0.2)=0.5$ (the threshold). $g(0.4) = 1/(1+e^{-2}) = 0.881$. $g(0) = 1/(1+e^{2}) = 0.119$ (symmetric about the threshold). Maximal slope $\beta/4 = 2.5$, at $x=0.2$.
\end{example}

\begin{example}[P7: Effective threshold]
$\theta=0$, $J=2$. Where along the $r$ axis is the midpoint of the S-curve $g(Jr+\hext)$ for $\hext=-1$? For $\hext=-0.4$? Which way did it move?

\textbf{Solution.} Midpoint $(\theta-\hext)/J$: $(0+1)/2 = 0.5$, and $(0+0.4)/2 = 0.2$. Raising $\hext$ moved it \emph{left}, from $0.5$ to $0.2$.
\end{example}

\begin{example}[P8: Stability by $\lambda$]
$\theta=0$, $\beta=20$, $J=1$, $\hext=-0.3$. One fixed point is $r^*=0.243$; check that it is one, and decide its stability. What about $r^*\approx0.0026$?

\textbf{Solution.} $g(0.243-0.3) = g(-0.057) = 1/(1+e^{1.14}) = 0.242\approx0.243$ \checkmark. $\lambda = 20\cdot0.243\cdot0.757 = 3.68>1$: unstable.
For $r^*=0.0026$: $\lambda = 20\cdot0.0026\cdot0.9974 = 0.052<1$: stable. (The third fixed point, $r^*\approx1$, is also stable: $\hext=-0.3$ is inside the bistable band.)
\end{example}

\begin{example}[P9: Can it be bistable at all?]
(a) $\beta=2$, $J=1$. (b) $\beta=20$, $J=0.15$. (c) $\beta=8$, $J=1$. For which can a suitable $\hext$ give two stable states?

\textbf{Solution.} Test $\beta J/4>1$: (a) $0.5$, no. (b) $0.75$, no. (c) $2$, yes. In (a) and (b) the S-curve is everywhere flatter than the identity line, so it crosses it once whatever $\hext$ is.
\end{example}

\begin{example}[P10: Linear as a special case]
Show that the stability rule $\lambda<1$ reproduces the linear autapse result.

\textbf{Solution.} $g(h)=h$ has $g'=1$ everywhere, so $\lambda = J\cdot1 = J$. The rule becomes $J<1$: stable, $J>1$: unstable, exactly as in the first half of the week.
\end{example}

\begin{example}[P11: Writing a bit]
With $\theta=0$, $\beta=20$, $J=1$, $\tau=10$\,ms, the neuron rests at the low state with $\hext=-0.5$. You can pulse $\hext$ to $0$. A 5\,ms pulse brings $r$ to $0.36$, a 15\,ms pulse to $0.76$. Which pulse stores a ``1''? Why does setting $\hext=-0.3$ forever not count as memory?

\textbf{Solution.} Only the 15\,ms pulse: $0.76$ is above the unstable fixed point $0.5$ of $\hext=-0.5$, so the rate continues to the high state; $0.36$ is below it and decays back. Memory means the state persists \emph{after} the input returns to its baseline;
a permanent change of $\hext$ is just a different input, not a stored bit.
\end{example}

\begin{example}[P12: Half-stable]
At the bifurcation point $\hext=-0.197$ ($\beta=20$, $J=1$), $r^*=0.053$. Is $g''(h^*)$ positive or negative, and from which side is the fixed point approached?

\textbf{Solution.} $g''=\beta^2g(1-g)(1-2g)$ with $g=0.053<0.5$, so $g''>0$. Then $\tau\dot{\dr} = \tfrac12J^2g''\dr^2>0$ on both sides: $r$ increases. From below ($\dr<0$) it moves up towards $r^*$; from above it moves away, up towards the high state.
Half-stable, approached from the left.
\end{example}

\section{Cheat sheet}

\begin{formula}[Week 02 on one page]
\begin{itemize}
  \item \textbf{Autapse}: a neuron's synapse onto itself, strength $J$. $\;\tau\dot r = -r + g(Jr+\hext)$. Excitatory: $J>0$ (positive feedback).
  \item \textbf{Linear} $g(h)=h$: $\;\tau\dot r = -(1-J)r + \hext$. Leak $-r$ vs.\ feedback $+Jr$.
  \item \textbf{Fixed point}: $\dot r=0$. Linear autapse: $r^* = \hext/(1-J)$ ($J\neq1$). For $0<J<1$, an amplification by $1/(1-J)$.
  \item \textbf{Stable}: nearby states return; \textbf{unstable}: nearby states run away. Only stable fixed points are seen in practice.
  \item \textbf{Perturbation}: $\dr = r-r^*$; $\tau\dot{\dr} = -(1-J)\dr$; $\dr(t) = \dr(0)e^{-(1-J)t/\tau}$. $\hext$ drops out.
  \item $J<1$: stable, decay time $\tau/(1-J)$ (slower as $J\to1$). $J>1$: unstable, divergence. $J=1$: border (no fixed point, or a whole line of them).
  \item \textbf{Full solution}: $r(t) = r^* + (r(0)-r^*)e^{-(1-J)t/\tau}$.
  \item \textbf{Vector field}: plot $\dot r$ vs.\ $r$; crossing zero going down = stable, going up = unstable.
  \item Stability = sign of the eigenvalue of the perturbation dynamics (here $-(1-J)/\tau$), as in Week 1.
\end{itemize}
\end{formula}

\begin{formula}[The non-linear autapse on one page]
\begin{itemize}
  \item \textbf{Logistic} $g(x) = 1/(1+e^{-\beta(x-\theta)})$: between $0$ and $1$, $g(\theta)=0.5$, $g' = \beta g(1-g)$, maximal slope $\beta/4$. $\beta\to\infty$: a step.
  \item \textbf{Fixed points}: $r^* = g(Jr^*+\hext)$, no closed form. Intersect the identity line with the S-curve $g(Jr+\hext)$ (effective gain $\beta J$, midpoint $(\theta-\hext)/J$; raising $\hext$ slides it left).
  \item \textbf{Stability}: $\lambda = Jg'(Jr^*+\hext)$ = slope of the S-curve at the crossing. $\lambda<1$ stable, $\lambda>1$ unstable; $\dr(t)=\dr(0)e^{-(1-\lambda)t/\tau}$. Linear $g$: $\lambda=J$.
  \item \textbf{Global} stability: reached from every start. \textbf{Local}: reached from nearby starts. Linearisation only tests local stability.
  \item \textbf{Bifurcation}: qualitative change from a smooth parameter change. \textbf{Saddle-node}: a stable and an unstable fixed point merge and vanish; the curves are tangent ($\lambda=1$).
  \item Book values $\theta=0$, $\beta=20$, $J=1$: three fixed points for $-0.803<\hext<-0.197$, otherwise one.
  \item \textbf{Attractor}: region all nearby trajectories go to. \textbf{Bistable}: two stable fixed points, an unstable one between them as the watershed.
  \item \textbf{Memory}: a brief pulse of $\hext$ past a bifurcation point flips the state, which persists after the pulse (the state depends on history).
  \item \textbf{Ingredients}: positive feedback ($\beta J/4>1$) and saturation.
  \item $\lambda=1$: second order, $\tau\dot{\dr} = \tfrac12J^2g''\dr^2$: \textbf{half-stable}, hyperbolic (slow) approach.
\end{itemize}
\end{formula}
